# Ecommerce Sales Analysis

## Project Overview

This project analyzes e-commerce sales data using Python to understand sales performance, customer behavior, and product-wise sales.

## Objective

The main objective of this project is to clean, analyze, and visualize e-commerce sales data and generate useful insights from the dataset.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Analysis Performed

- Data cleaning and preprocessing
- Customer-wise sales analysis
- Product-wise sales analysis
- Total sales calculation
- Data aggregation using Pandas
- Data analysis using NumPy
- Sales data visualization

## Project Files

- `analysis.ipynb` — Main data analysis notebook
- `visualzation.ipynb` — Data visualization notebook
- `graph.py` — Python script for generating graphs
- `order.csv` — E-commerce sales dataset

## Key Skills Demonstrated

- Python programming
- Pandas data manipulation
- NumPy data analysis
- Data visualization
- Exploratory Data Analysis (EDA)
- Working with CSV datasets

## How to Run

1. Clone this repository.
2. Install the required Python libraries.
3. Open the Jupyter Notebook.
4. Run the analysis and visualization cells.
